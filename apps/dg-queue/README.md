# DG Queue

DJ mix map of songs already in the library: frat/nostalgia with a Death Grips spike.

Runs on **8890**. Spec: [docs/dg-queue-remix.md](../../docs/dg-queue-remix.md).

```bash
cd apps/dg-queue
npm install
npm run dev
```

Open [http://127.0.0.1:8890](http://127.0.0.1:8890). Six mixes in the header (`#dg-queue`, `#friday-night`, `#club`, `#texan`, `#karaoke`, `#porch`). Play walks the cue sheet. It does not play the recordings.
